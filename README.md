# BlockCraft PE

Protótipo de jogo voxel 3D inspirado em jogos de construção por blocos, feito para navegador e preparado para controles de PC e Android.

## Recursos atuais
- Mundo 3D com terreno procedural simples
- Blocos de grama, terra, pedra e madeira
- Quebrar e colocar blocos
- Movimentação WASD
- Câmera em primeira pessoa
- Pulo
- Hotbar para selecionar blocos
- Controles básicos para tela touch
- Renderização WebGL com Three.js via CDN

## Executar
Abra `index.html` em um servidor web local ou publique o repositório com GitHub Pages.
